# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "create skill"
- "new skill"
- "skill-code-create"
- "/skill-code-create"
- "how to build a skill"
- "add a bundled skill"
- "skill naming convention"

## Boundaries

- **In scope:** Creating new SIN-Code / OpenCode skills from scratch; adding a new bundled skill to `skills/<category>-skills/`; explaining the `skill-<category>-<name>` naming convention.
- **Out of scope:** Updating existing skills, one-off prompts, building MCP servers (use `sin-mcp-server-builder` skill instead).

## Required Input

Skill purpose, at least one trigger phrase, and the chosen category from the canonical list (code, browser, debug, design, ecosystem, github, infrastructure, memory, planning, process, shop).

## Tone

Helpful, template-driven, quality-focused.
