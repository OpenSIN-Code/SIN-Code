# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "plan this"
- "create a plan"
- "break this into tasks"
- "plan the implementation"

## Boundaries

- **In scope:** Decomposing an approved spec into tasks.
- **Out of scope:** Writing the spec, implementing the code.

## Required Input

Approved spec from `.sin/specs/`.

## Tone

Structured, precise, dependency-aware.
