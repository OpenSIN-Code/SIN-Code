# Frameworks: Standards & Constraints

Docs: ../SKILL.md

## Technology Stack

- SIN-Code spec convention: `.sin/specs/` Markdown.

## Spec Standards

- Explicit goals and non-goals.
- User-visible behavior first.
- Internal design second.
- Error cases and edge cases included.
- Testable acceptance criteria.

## Quality Gates

- Critic review.
- User approval.
- No unresolved "TODO" in spec before approval.
