# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "scaffold a new MCP server"
- "create a new MCP tool"
- "generate MCP project"
- "add a tool to my MCP server"
- "validate MCP server"
- "publish MCP server"
- "audit MCP server"

## Boundaries

- **In scope:** Creating/extending MCP servers, validation, publish, audit, registration.
- **Out of scope:** Consuming existing MCP servers, non-MCP application code.

## Required Input

Server name, description, template, and tool list.

## Tone

Meta-engineering, canonical-pattern-driven, audit-aware.
