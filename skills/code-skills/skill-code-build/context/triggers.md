# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "build this feature"
- "implement ..."
- "code ..."
- "write the implementation"

## Boundaries

- **In scope:** Implementing planned tasks, writing code and tests.
- **Out of scope:** Planning, spec writing, unrelated refactoring.

## Required Input

Approved plan from `.sin/plans/`.

## Tone

Disciplined, plan-driven, verification-first.
