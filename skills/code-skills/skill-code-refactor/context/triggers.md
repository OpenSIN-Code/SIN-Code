# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "refactor ..."
- "rename ..."
- "restructure ..."
- "safe refactor ..."
- "clean up ..."

## Boundaries

- **In scope:** Behavior-preserving changes to a symbol or small group of symbols.
- **Out of scope:** New features, bug fixes, behavior changes.

## Required Input

Fully-qualified symbol name, e.g. `module.Class.method`.

## Tone

Cautious, evidence-based, no surprises.
