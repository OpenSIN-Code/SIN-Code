# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "spec this out"
- "write a spec"
- "design this feature"
- "how should we implement ..."

## Boundaries

- **In scope:** Requirements gathering, design decisions, spec writing.
- **Out of scope:** Implementation, planning, coding.

## Required Input

Feature idea or requirement from the user.

## Tone

Inquisitive, clear, decision-forcing.
