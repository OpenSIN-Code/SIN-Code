# Frameworks: Standards & Constraints

Docs: ../SKILL.md

## Technology Stack

- `sin-doc-coauthoring` MCP server / CLI.
- Document state stored in `~/.config/sin-doc-coauthoring/sessions/`.

## Standards

- Always gather context before outlining.
- Draft each section with clarifying questions.
- Review before export.
- Export to the requested destination.

## Constraints

- Do not use for code companion files.
- Do not skip review for external-facing docs.

## Quality Gates

- Outline approved.
- All sections drafted.
- Review passed.
- Export successful.
