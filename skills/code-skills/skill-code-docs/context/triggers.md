# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "write a README"
- "create an ADR" / "draft a spec"
- "design doc" / "RFC" / "API docs"
- "changelog"
- "coauthor a document"

## Boundaries

- **In scope:** Standalone documents (README, ADR, SPEC, DESIGN, RFC, API, CHANGELOG).
- **Out of scope:** `.doc.md` companions, images, inline code comments.

## Required Input

Document type and title.

## Tone

Collaborative, structured, quality-focused.
