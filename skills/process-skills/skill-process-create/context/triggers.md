# Triggers

## Direct Triggers

- "create skill"
- "new skill"
- "skill-process-create"
- "/skill-process-create"
- "how to build a skill"
- "how do I create a skill"

## Situational Triggers

- User wants a reusable agent capability.
- User wants to add a new skill to the SIN-Code repository.
- User is unsure which category or name a skill should use.
- User needs to validate an existing skill directory.

## Anti-Triggers

- One-off prompts without reuse value.
- Existing skill updates.
- MCP server scaffolding (route to `sin-mcp-server-builder`).
