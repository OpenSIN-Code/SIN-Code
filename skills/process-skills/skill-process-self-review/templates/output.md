# Output-Template

Siehe `references/report-template.md` für das vollständige Berichtsformat.

Der Bericht MUSS alle 6 Abschnitte enthalten:
1. Geprüfter Umfang
2. Anforderungsabgleich
3. Findings (BLOCKER/MAJOR/MINOR/NIT)
4. Verifikationsergebnisse
5. Durchgeführte Korrekturen
6. CEO-Veto (Status)
