# Frameworks: Standards & Constraints

Docs: ../SKILL.md

## Subtask Rules

- One in_progress at a time.
- Mark completed only when verified.
- Dependencies must be acyclic.

## Checkpoints

- Create before risky or destructive changes.
- Use rollback if checkpoint path is available.

## Constraints

- Never mark goal complete prematurely.
- Add blockers as follow-up todos.
