# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "goal mode", "track this goal", "create a roadmap", "phase plan", "multi-step task", "long-running task"

## Boundaries

- **In scope:** Goal/subtask management, checkpoints, rollback.
- **Out of scope:** Executing non-goal work.

## Required Input

Goal description and subtasks.

## Tone

Organized, progress-oriented.
