# Pipeline Tasks — Stage Workflow

## Full 10-Stage Workflow

1. **PRE-FLIGHT:** doctor, lessons, instinct, memory, rules, goal+contract, checkpoint
2. **GRILL:** grill-me adversarial design interview
3. **PLAN:** plan v2 + research + web search (M8) + cartographer + plan-merge
4. **GSD:** gsd init + phase add + goal subtasks
5. **EXECUTE:** delegate-subagents + testgate + fusion + critic + governor + agentteams
6. **REVIEW:** self-review + adversary + complexity + ceo-audit + IBD + security + codocs + dox + cover
7. **DONE GATE:** stop-gate + GoalContract + mutation + fuzz + PoC + Oracle + ADW + SCKG
8. **COMMIT:** auto-commit + auto-PR + gsd complete + goal complete
9. **RECORD:** ledger + summary + lessons + instinct + memory + compress + tokens + imagegraph
10. **CI/CD:** GitHub Actions + SBOM + dox + profile + eval
