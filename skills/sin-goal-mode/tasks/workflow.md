# Tasks: Workflow

Docs: ../SKILL.md

## Pre-flight

- [ ] Define goal and success criteria.
- [ ] List subtasks.

## Execution

- [ ] Create goal.
- [ ] Add subtasks.
- [ ] Add dependencies.
- [ ] Pick first unblocked subtask.
- [ ] Mark subtask in_progress.
- [ ] Execute subtask.
- [ ] Mark subtask complete.
- [ ] Repeat until done.
- [ ] Create checkpoint before risky work.
- [ ] Complete goal.

## Post-flight

- [ ] Report goal status and blockers.
