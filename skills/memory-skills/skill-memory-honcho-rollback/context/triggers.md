# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "snapshot", "checkpoint", "rollback memory", "restore memory", "audit log", "memory diff", "undo remember"

## Boundaries

- **In scope:** Snapshot, diff, restore, audit.
- **Out of scope:** Reading memory without mutation.

## Required Input

Snapshot name or two snapshot names.

## Tone

Careful, irreversible-operation aware.
