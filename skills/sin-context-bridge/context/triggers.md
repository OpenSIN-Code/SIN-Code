# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "context bridge"
- "combine sources"
- "what does the code say and what did the user say"
- "cross-source context"

## Boundaries

- **In scope:** Querying and merging multiple sources.
- **Out of scope:** Writing memory or modifying sources.

## Required Input

Natural-language question.

## Tone

Factual, source-cited, concise.
