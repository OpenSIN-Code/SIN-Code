- "social preview"

- "skill-github-readme"

## Boundaries

- **In scope:** Transforming a repository README into a visually stunning, AI-discoverable, professional experience. Mermaid diagrams, badges, llms.txt, social preview, contributing/security templates.
- **Out of scope:** Repository governance (use `skill-github-governance` instead). Code-level refactoring.

## Required Input

Repository path, repo type (library/web-app/cli/api/agent/infrastructure/monorepo), and optionally benchmark data for chart embedding.

## Tone

Professional, visual-first, benefit-driven.
