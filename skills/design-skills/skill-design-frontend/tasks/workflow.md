# Tasks: Workflow

Docs: ../SKILL.md

## Pre-flight

- [ ] Identify component or page to create/review.
- [ ] Confirm target framework (react, vue, svelte, html).

## Execution

- [ ] Task 1: Load design system.
  - Acceptance: Tokens and philosophy available.
  - Verify: `design_system_load` used.
- [ ] Task 2: Create component or scaffold page.
  - Acceptance: Spec or scaffold generated.
  - Verify: Output matches design system.
- [ ] Task 3: Review existing UI (if applicable).
  - Acceptance: Inconsistencies identified.
  - Verify: Review report produced.
- [ ] Task 4: Extract/export tokens (if applicable).
  - Acceptance: Tokens extracted or exported to Figma JSON.
  - Verify: Output valid.
- [ ] Task 5: Accessibility check.
  - Acceptance: WCAG 2.2 AA check passed.
  - Verify: No contrast or a11y errors.
- [ ] Task 6: Deliver.
  - Acceptance: Code/spec ready for use.
  - Verify: User receives output.

## Post-flight

- [ ] Summarize design decisions.
- [ ] Note any a11y fixes or token exports.
