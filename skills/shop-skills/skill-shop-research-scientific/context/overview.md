# Overview

This skill covers three public scientific databases:

- **PubMed** (biomedical literature, NCBI/NLM)
- **USPTO** (United States patents and published applications)
- **arXiv** (physics, math, CS, quantitative biology preprints)

Use the built-in HTTP tool (`sin_http_get`) or `native_websearch` to query these endpoints. Never fabricate URLs, titles, or abstracts. If a search returns no results, say so explicitly.
