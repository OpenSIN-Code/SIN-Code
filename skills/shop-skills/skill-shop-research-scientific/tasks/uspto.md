# USPTO Patent Search Strategy

1. Search the USPTO Patent Public Search:
   `https://ppubs.uspto.gov/pubwebapp/static/pages/ppubsbasic.html`
2. For structured data, use the Patent Public Search API or the Open Data Portal (if available). Prefer official URLs.
3. Extract patent number, title, abstract, inventors, assignee, and filing date.
4. Cite with `https://patents.google.com/patent/US<number>` or the USPTO direct link when available.
5. Warn if the full text is not public-domain or requires login.
