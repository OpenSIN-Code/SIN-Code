# Context: Triggers & Boundaries

Docs: ../SKILL.md

## Trigger Phrases

- "browse", "visit", "screenshot", "scrape", "click", "fill form", "web automation", "test this page"

## Boundaries

- **In scope:** Navigation, observation, interaction, scraping.
- **Out of scope:** API calls, credential submission.

## Required Input

URL or target web page.

## Tone

Careful, observational, interaction-aware.
