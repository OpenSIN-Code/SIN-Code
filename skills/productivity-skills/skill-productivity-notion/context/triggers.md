# Triggers

Activate this skill when the user:
- Mentions "Notion" in any context (read, search, edit, create)
- References Notion-specific concepts: pages, databases, blocks, comments, workspaces
- Uses German equivalents: "Notion durchsuchen", "Notion Seite", "Notion Datenbank"
- Asks about roadmaps, sprints, wikis, or project tracking stored in Notion
- Wants to create, update, or archive Notion content
- Needs to search across Notion workspaces

Do NOT activate for:
- Generic document editing (use sin_write/sin_edit)
- Non-Notion project management tools
- General web search (use sin_web_search)
